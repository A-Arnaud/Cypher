# Cypher 0.8.0 — AI Quota Monitor for Windows and macOS

Cypher is a local AI quota monitor for Windows and macOS. This version makes Cypher easier to use: a guided account setup, compact quota cards, reset countdowns and clearer settings. One release contains **Windows x64, Mac Intel and Mac Apple Silicon**. [Guide en français](https://github.com/A-Arnaud/Cypher/blob/main/docs/demarrage-fr.md).

## New in this version

- **An easier start:** choose Codex, Claude Code or Gemini. Existing accounts are offered first; unconfigured placeholder services no longer fill your quota view.
- **Browser sign-in first for Codex:** the recommended button is immediately visible. CLI, profile import and API alternatives are grouped under Other ways to connect.
- **Readable quota cards:** remaining amounts and reset countdowns together, with a clear retry/connect action when attention is needed. Source details are available on demand.
- **Light, dark or system appearance:** your preference is saved. Monochrome provider icons remain readable in either theme.
- **Simpler Settings:** appearance, language, indicator, optional startup and updates are easy to find. Refresh frequency, opacity, shortcut and private diagnostics are in Advanced options.
- **A quieter window:** smaller cards, a compact minimize button at the bottom and no unknown-plan labels on the account overview.

Claude Code connection/account reads remain available; Claude/Gemini subscription percentages are not collected by their current connectors. API billing remains separate.

## Update proposals

- A small footer/menu action appears when a newer compatible stable release is found. No window opens, Dock bounce or OS notification interrupts your work.
- Checks run about 30 seconds after startup, then every six hours. **Settings → Updates** offers manual checking and an automatic-check switch.
- **Later** hides the notice for 24 hours. Detection alone never downloads or installs anything.
- **Installed Windows:** after confirmation, Cypher downloads and verifies the installer, closes its readers/indicator, installs and restarts in the bar. The download can be cancelled.
- **Current Mac builds and Windows portable/extracted copies:** confirmation opens the correct official download in your browser. Replacement remains manual. Mac native automatic installation needs the Apple signing setup and a future signed-client integration.

**Installed Windows 0.6.0 or later:** check Settings for this update, approve it and let Cypher install/restart. **Mac/portable:** replace manually using the correct download. **Older 0.5.x:** install the current version manually once to acquire the checker.

## Install or replace the app

1. **Quit the old Cypher completely** from its bar menu or closing dialog.
2. **Windows:** run the installer. **Mac:** open the correct DMG, replace Cypher.app in Applications and reopen it.
3. Keep the separate local user-data folder to retain preferences and profiles.

Windows remains unsigned; Mac builds are ad-hoc signed and **not notarized by Apple**. These update features do not remove first-launch security prompts. [Installation help](https://github.com/A-Arnaud/Cypher/blob/main/docs/downloads.md#first-launch).

## Existing features retained

Automatic connection detection, Codex browser sign-in without an external CLI, labelled bar-placement controls, Minimize / Quit / Cancel choices and optional login startup remain available. Mac remains a discreet top-menu app without a running-app Dock/Command-Tab icon, including when opening Settings. Windows uses the bottom taskbar/notification area. ## Verification and limits

Synthetic tests cover release/architecture selection, consent, cancellation, 24-hour deferral and failure handling. The real Electron NSIS download engine is exercised with synthetic files, including rejection of incorrect SHA-256/SHA-512; no installer runs in that test. The published `latest.yml` is checked against the actual Windows installer.

Windows and both Mac CI jobs validate and package the source used for this release. Hosted Windows Server checks do not prove every Windows 10/11 Explorer scenario. Automated checks do not represent a real future-version upgrade, Apple notarization or every provider account. Exact results are recorded in [VERIFICATION.md](https://github.com/A-Arnaud/Cypher/blob/main/VERIFICATION.md).
