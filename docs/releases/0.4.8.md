# Cypher 0.4.8

Your AI usage, always in view. This first GitHub release ships the latest Cypher Windows widget with an English presentation and English first-launch experience.

## Downloads

| Asset | Purpose |
| --- | --- |
| `Cypher-Setup-0.4.8-win-x64.exe` | Per-user Windows installer; supports automatic Windows startup |
| `Cypher-0.4.8-win-x64.exe` | Portable app; no installation or automatic Windows startup |
| `SHA256SUMS-0.4.8.txt` | SHA-256 checksums for both executables |

Download the three files from this release. In PowerShell, use `Get-FileHash .\Cypher-Setup-0.4.8-win-x64.exe -Algorithm SHA256` (or the portable filename) and compare the result with the checksum file.

## What's included

- Compact, reorderable profile rows, detailed cards and a native Windows taskbar indicator.
- Provider-reported Codex quota windows; supported API key budgets, balances, points and organization spending; local model inventories.
- Accurate display of zero values, currencies, quota durations and last observation times.
- Stale-data handling, identity-aware balance clearing when a key is replaced, and bounded retry backoff.
- Recoverable loading errors, safe shortcut editing and validated preference recovery.
- English documentation, original Cypher presentation artwork and synthetic English screenshots. New profiles start in English; saved language preferences and optional French remain supported.

See the [changelog](https://github.com/A-Arnaud/Cypher/blob/main/CHANGELOG.md) and [provider coverage](https://github.com/A-Arnaud/Cypher/blob/main/docs/catalog-coverage.md) for detailed capabilities and boundaries.

## Validation for this release

- TypeScript check passed; **108 unit tests** and **15 browser tests** passed.
- Separate test package passed isolated first-run checks with synthetic API responses, real IPC and Windows DPAPI; native window-corner checks passed.
- Production package passed Electron fuse, CSP, archive-content and startup/injection/debugging checks.
- Source/history secret scans and the production archive scan reported no recognized secrets. Dependency audit reported no known vulnerabilities at check time.

These checks do not prove that every provider works with every real account. CLI permissions are per profile; no real account login was performed for this release.

## Before you run

Verified target: **Windows 10 x64, horizontal primary taskbar**. Windows 11, vertical/secondary taskbars and untested DPI setups are not certified. End users do not need Node.js; CLI integrations need the relevant official CLI.

Executables are **not Authenticode-signed** and Windows may show a warning. The installer does not require administrator rights. Portable startup includes Electron extraction and can take longer. API keys you enter are encrypted for your Windows session; this does not protect against malware running as you. See [Security](https://github.com/A-Arnaud/Cypher/blob/main/SECURITY.md) and [Privacy](https://github.com/A-Arnaud/Cypher/blob/main/PRIVACY.md).
