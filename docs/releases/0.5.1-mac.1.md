# Cypher 0.5.1-mac.1 — macOS preview

> Older release. For current Windows and Mac downloads, use [Latest](https://github.com/A-Arnaud/Cypher/releases/latest). [Release history](README.md).


Separate macOS preview for **Apple Silicon (arm64)** and **Intel (x64)**. The Windows 0.5.0 downloads remain available unchanged.

- Native **top-right menu bar** indicator, with up to three pinned quota readings, stale markers and a count of additional profiles.
- Menu actions to show/hide the widget, refresh, pause and quit; macOS template icon follows the system appearance.
- macOS CLI discovery, executable selection and isolated official sign-in through Terminal.
- English and French menu bar labels and settings; API keys encrypted through the macOS Keychain.

Download the `.dmg` matching your processor, then drag **Cypher.app** into **Applications**. ZIP alternatives and SHA-256 checksum files are included.

**Preview limitations:** ad-hoc signature only; no Apple Developer ID or notarization. Gatekeeper may require **System Settings → Privacy & Security → Open Anyway**. Automatic login registration is disabled; add Cypher manually in Login Items if needed. Provider quota limitations are unchanged. Live-account and hands-on physical Mac validation remain outstanding.

Build verification runs on macOS 15 for both architectures: unit and synthetic CLI tests, Electron docking/restore, final packaged app launch/signature verification, and publication scans.

See the [macOS guide](https://github.com/A-Arnaud/Cypher/blob/main/MACOS.md) for installation, CLI setup and verification boundaries.
