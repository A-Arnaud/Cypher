## Start with your computer, directly in the bar

Enable **Settings → Start with Windows** or **Settings → Open at login** on Mac if you want Cypher to launch automatically. In French: **Réglages → Démarrer avec Windows / Ouvrir à la connexion**.

- At sign-in, Cypher starts directly in the **bottom Windows taskbar** or **top Mac menu bar**, without opening its window. This also works if you previously removed the indicator or left Cypher in its detailed view.
- Automatic startup is **optional**. Placing Cypher in the bar or minimizing no longer enables it implicitly. Turn the Settings switch off whenever you want to stop automatic startup.
- Mac now offers native login-item registration from Cypher Settings once installed in Applications. If macOS requires approval, Cypher displays that status and explains where to approve it in **System Settings → General → Login Items**. Registration is verified, and changes made in system settings are reflected when you return to Cypher.
- Opening Cypher yourself still opens its window. If the indicator cannot initialize at sign-in, the window opens with an error so the app remains accessible.

The clear bar-placement button and **Minimize / Quit / Cancel** closing choices introduced in 0.5.2 remain available.

## Installation help and other formats

Windows executables are unsigned. Mac builds are ad-hoc signed and **not notarized by Apple**; first-launch prompts and login-item reliability can still depend on macOS approval/signing. Cypher reports rejected login registration instead of assuming success. Windows portable builds do not support automatic startup.
