# Cypher 0.5.1-mac.2 - connection options

> Older release. For current Windows and Mac downloads, use [Latest](https://github.com/A-Arnaud/Cypher/releases/latest). [Release history](README.md).


Mac preview for **Apple Silicon (arm64)** and **Intel (x64)**, requiring **macOS 13 Ventura or later**. The Windows 0.5.0 stable downloads remain available.

## Connect your accounts

- **Automatic detection first:** existing profiles and their read permissions remain at the top of Connections.
- **More ways to connect:** expandable choices keep optional methods together.
- **Codex browser sign-in:** connect a new account without installing Node, a CLI or the Codex application. Cypher includes the unmodified official Codex 0.164.0 executable and uses its authentication/account protocol. Login opens in your normal browser and creates an independent profile in Cypher. Reads are authorized only after successful authentication. Pending browser login can be cancelled.
- **Installed CLI:** keep the existing official Terminal/Windows CLI sign-in, account creation, executable selection and profile-folder import.
- **API key:** OpenAI and Anthropic API billing connections are available as separate alternatives. API billing is not a ChatGPT or Claude subscription quota.

Direct browser login is currently implemented for **Codex only**. Claude and Gemini still use their existing CLI connection methods; their subscription quota readers remain unimplemented. Neither a browser page nor an installed app alone establishes quota support.

## Downloads and first launch

Choose the DMG or ZIP for your processor: **Intel = mac-x64**, **Apple Silicon = mac-arm64**. Move Cypher.app to Applications. The menu bar indicator remains at the **top right**.

This preview is **ad-hoc signed, without Apple notarization**. It can still require **System Settings > Privacy & Security > Open Anyway** on first launch. The Developer ID pipeline is prepared, but no Apple Developer membership or signing credentials are configured. No claim of notarization is made.

Included Codex authentication code increases download size. No account, credentials, generated content or user settings are bundled. User accounts must be authorized explicitly; real-account sign-in and quota readings are not covered by synthetic tests.
