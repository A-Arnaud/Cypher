## Easier to find, easier to close

- **An explicit bar button:** **Move to taskbar** on Windows, **Move to menu bar** on Mac. It is visible in both compact and detailed views, with a hint explaining where Cypher will appear: bottom on Windows, top right on Mac.
- **A clear closing choice:** the X and native window close ask whether to **Minimize**, **Quit Cypher** or **Cancel**. Minimizing keeps collection running; quitting stops the application. Cypher checks that its indicator is ready before hiding. If placement fails, the window remains open.
- **French and English:** including “Mettre dans la barre des tâches / des menus”, “Quitter Cypher” and “Annuler”.
- **Connection options on both platforms:** automatic detection stays first, followed by browser sign-in, CLI, profile import and supported API alternatives. Codex browser sign-in includes the official authentication component; no external CLI, Codex app or Node installation is needed. API billing remains separate from subscriptions; Claude/Gemini subscription sign-in still uses their CLI.

Windows 10 retains the embedded horizontal-primary-taskbar indicator. Windows 11 uses the notification area near the clock; its icon may be under hidden icons. Mac uses the native menu bar. Existing releases remain available in the version history.
