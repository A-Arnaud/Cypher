# Cypher 0.4.9

> Older release. For current Windows and Mac downloads, use [Latest](https://github.com/A-Arnaud/Cypher/releases/latest). [Release history](README.md).


The graphite firefly identity now appears throughout the current application and repository presentation. This release also completes the contributor and feedback paths without changing provider capabilities.

## Download

- **`Cypher-Setup-0.4.9-win-x64.exe`** — per-user Windows x64 installer, with optional Windows startup.
- **`Cypher-0.4.9-win-x64.exe`** — portable Windows x64 application, without automatic Windows startup.
- **`SHA256SUMS-0.4.9.txt`** — SHA-256 checksums for both executables.

Use `Get-FileHash .\Cypher-Setup-0.4.9-win-x64.exe -Algorithm SHA256` in PowerShell (or the portable filename) and compare the result with the manifest. Executables remain **not Authenticode-signed**; Windows may display a warning. End users do not need Node.js.

## Changes

- Supplied graphite firefly logo in the desktop/compact interface, tray, main executable, portable launcher, installer and native helper.
- Regenerated README wordmark, presentation cards, banner and English screenshots using account-free synthetic fixtures. Provider logos remain unchanged.
- Self-contained icon generation from the checked-in source, replacing a developer-machine path. A Windows resource check compares actual executable icons with the intended ICO; CI now runs it too.
- Clearer product, download, provider-status and contribution navigation; a concise contributor guide; bug, feature and provider request forms; support FAQ; security-reporting entry point; and a launch checklist.

English remains the default for new profiles. Saved language preferences, CLI profiles and permissions remain compatible. **No additional provider quota connector is claimed by this release.** See [provider coverage](https://github.com/A-Arnaud/Cypher/blob/main/docs/catalog-coverage.md).

## Validation and limits

TypeScript, **108 unit tests** and **15 browser tests** passed. Separate packaged first-run and native-window checks passed using isolated settings and synthetic API responses. Production security checks and source/history/archive secret scans passed; the dependency audit reported no known vulnerabilities at check time.

The packaged frontend/tray assets match the new source assets. Windows icon resources were extracted from the main app, helper, installer and portable executable and compared with the new ICO.

Verified native target remains **Windows 10 x64 with a horizontal primary taskbar**. Windows 11, other taskbar/DPI configurations and every live provider account are not certified. Scans do not guarantee the absence of every secret or vulnerability. See [Security](https://github.com/A-Arnaud/Cypher/blob/main/SECURITY.md), [Privacy](https://github.com/A-Arnaud/Cypher/blob/main/PRIVACY.md) and the [verification record](https://github.com/A-Arnaud/Cypher/blob/main/docs/release-verification-2026-10-26.md).
