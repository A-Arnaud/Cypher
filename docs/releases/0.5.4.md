> Older version. For a new installation, use [Latest](https://github.com/A-Arnaud/Cypher/releases/latest) and the [current update guide](../updates.md).

## Included improvements

| Area | Current behavior |
| --- | --- |
| **Connections** | Automatic detection comes first. Additional options include Codex browser sign-in without a separately installed CLI, profile import, installed CLI sign-in and supported API-key alternatives, on Windows and Mac |
| **Bar controls** | A visible **Move to taskbar** button on Windows or **Move to menu bar** on Mac explains where to find Cypher |
| **Closing** | The X offers **Minimize**, **Quit Cypher** and **Cancel**. Minimizing keeps collection running; quitting stops the app |
| **Optional startup** | Enable **Settings → Start with Windows** or **Open at login** on Mac. At sign-in, Cypher opens directly in the bar without showing its window |
| **Discreet Mac app — new in 0.5.4** | Cypher stays in the top menu bar without a running-app icon in the Dock or Command-Tab, including after reopening its window or Settings |

Windows 10 uses the supported horizontal primary taskbar at the bottom. Windows 11 uses the notification area near the clock; its icon may be under hidden icons. Mac uses the top-right menu bar on Intel and Apple Silicon.

On Mac, click Cypher at the top and choose **Show / Hide** (**Afficher / Masquer**) to open or hide its window. **Control+Option+Q** and reopening the app from Applications also restore it. **Quit** (**Quitter**) remains available in that menu. Windows uses **Ctrl+Alt+Q** for show/hide.

Automatic startup remains optional: moving into the bar does not enable it. Mac startup requires the app in Applications and may require approval in Login Items. Cypher reports pending approval or registration failure. Windows portable builds do not support automatic startup.

Codex browser sign-in includes the official authentication component; no external Codex CLI/app or Node installation is needed. Browser sign-in is implemented for **Codex only**. Claude/Gemini subscription sign-in still uses their CLI; their subscription quota readers are not implemented. API billing remains separate from chat subscriptions. [Connection details](https://github.com/A-Arnaud/Cypher/blob/main/docs/connection-methods.md).

## Install or update

1. **Quit the previous Cypher completely.** Choose Quit in the bar menu or Quit Cypher in the closing dialog; minimizing leaves the old process running.
2. **Windows:** run the installer. **Mac:** replace Cypher.app in Applications with the app from the correct DMG, then reopen it.
3. Existing preferences/profiles remain in the separate local data folder. Keep that folder when updating the application.

If you had pinned Cypher to the Mac Dock, remove that favorite once through **Options → Remove from Dock**. An older running process or manually pinned favorite is separate from the new version's menu-only behavior.

Windows downloads remain unsigned; Mac builds are ad-hoc signed and **not notarized by Apple**. First-launch signing prompts and login-item approval are separate from Dock behavior.
