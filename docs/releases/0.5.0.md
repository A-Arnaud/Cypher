# Cypher 0.5.0 — Windows 10 and Windows 11

One x64 download, with a Windows-version-aware presentation. The graphite firefly identity and existing provider/permission behavior are retained.

## Download

- **`Cypher-Setup-0.5.0-win-x64.exe`** — per-user Windows 10/11 x64 installer, with optional Windows startup.
- **`Cypher-0.5.0-win-x64.exe`** — portable Windows x64 build; automatic Windows startup is unavailable in portable mode.
- **`SHA256SUMS-0.5.0.txt`** — checksums for both executables.

No Node.js installation is required for end users. Executables are **not Authenticode-signed**; Windows may display a warning. Verify the SHA-256 manifest before running a download.

## Windows presentations

- **Windows 10:** existing embedded percentage indicator on a horizontal primary taskbar, plus desktop widget.
- **Windows 11:** native notification-area icon (system tray), with percentage tooltip/menu and access to the desktop widget. Windows may place it under hidden icons. This is **not an embedded text indicator inside the Windows 11 taskbar**.
- Legacy Explorer manipulation is blocked on unsupported/newer versions by a native version guard; the independent startup registry query remains available.
- Saved taskbar-mode settings restore through the selected backend. Show/hide, refresh, pause/resume and quit remain accessible. Labels and guidance are available in English and French.

Compact indicators display available remaining percentages only. API balances/spending, points and model counts remain available in the widget/details and are not converted into invented percentages. Provider coverage is unchanged; this release does not implement Claude/Gemini quota reads.

## Validation and limits

Locally on **Windows 10 x64 build 19045**: **132 unit tests across 26 files**, **16 Edge UI scenarios**, TypeScript, a real Electron Tray/Menu smoke, isolated packaged first-run checks (12), native-window checks (4), production security checks, executable icon comparisons, source/history/archive secret scans and dependency audit passed. Installer and portable were built with publication disabled. A fresh independent review was completed and its documentation mismatch corrected.

**A real Windows 11 device was not available.** Injected OS-version tests, browser fixtures, a tray smoke on Windows 10 and GitHub Windows Server automation do not certify Windows 11 Explorer, display scaling, startup or install behavior. Windows 11 device feedback is welcome through the bug-report form with the exact `winver` build and install type.

No real provider account or PC reboot was tested. The user's running installation and settings were not replaced during verification. Scans are not a guarantee that every vulnerability is absent. ARM64 is not a native build target.
