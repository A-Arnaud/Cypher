# Cypher visual guide

[Download](../downloads.md) · [README](../../README.md) · [Guide en français](../demarrage-fr.md) · [Mac setup](../../MACOS.md)

The gallery shows **Cypher 0.9.0**, with 25 captures of its actual interface and 12 annotated guides. Click an image for full resolution. All accounts, settings and values are demonstrations.

The Windows 10 desktop scenes are **staged in a native WinForms harness**, using the real Cypher panel and production C# indicator painter. The desktop, notes window, system icons and clock are demonstration context. They are not captures of a personal desktop or evidence of a new shell integration. Windows 11 and Mac context images are explicitly labelled layout previews and use the actual native indicator compositor.

## Reproduce the images

On Windows, after installing development dependencies:

```powershell
npm run build
node scripts/capture-github.cjs
node scripts/capture-indicators.cjs
node scripts/capture-windows-showcase.cjs
node scripts/generate-screenshot-guides.cjs
node scripts/generate-brand-assets.cjs
node scripts/generate-github-panels.cjs
```

The browser captures block external requests and never load the production bridge. The native harness paints to offscreen bitmaps; it neither attaches to Explorer nor reads the current desktop, local accounts, credentials or OS startup preferences. Callout positions for the minimize button come from the captured DOM geometry. The native Windows scene and real indicator share the same deterministic demonstration fixture. The generator records guide filenames in [the manifest](../showcase/manifest.json).
