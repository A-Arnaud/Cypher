# Cypher public positioning and search visibility

Use **Cypher — AI Quota Monitor** as the public product heading, paired immediately with **Codex quota monitor for Windows and macOS**. Keep the application and repository named Cypher. Describe what it does before listing architecture or catalog size.

## Why another project was easier to find

The earlier comparison found OpenTokenUsage quickly and failed to surface Cypher. Its descriptive [site title](https://opentokenusage.app/) names Claude Code, Codex, usage tracking and Windows. On October 27, 2026, a fresh generic query `Codex Claude quota Windows tray` returned several competing tools with explicit product descriptions. The tested queries `Cypher quota monitor Codex Claude Windows Mac A-Arnaud`, `"Cypher" "quota" "A-Arnaud"` and `site:cypher-os.me` did not surface this project in the returned results. Other Cypher searches returned unrelated products and Neo4j documentation. These are observations of this search tool at this date, not universal rankings or proof of Google's index status.

The live Cypher homepage returned HTTP 200, but its title was `Cypher — Your AI tools, always in view`. Its description referred to a Windows desktop, omitted Codex and macOS, and called the project open source despite no project-wide open-source license being declared. That mismatch leaves both readers and search engines with a weaker description of the actual app.

Clear naming and matching search intent are plausible contributors to the visibility difference. Indexing, external references and competition can also matter; their individual effects have not been measured. [Google's title guidance](https://developers.google.com/search/docs/appearance/title-link) recommends descriptive titles consistent with visible page content. Metadata changes do not guarantee placement or immediate discovery.

## Keep the promise accurate

- Codex subscription quotas and reset countdowns are the main search promise.
- Windows taskbar/system tray and macOS menu bar describe the actual platform behavior; Windows 10 and 11 differ as documented in the [README](../README.md#windows-and-mac).
- Claude Code connection/account/plan reads are available. Claude and Gemini subscription quota percentages are not collected by their current connectors. Do not advertise those percentages to attract traffic.
- API spending and balances remain separate from subscription quotas. Follow the [coverage matrix](catalog-coverage.md).
- A public repository is not automatically open source. Do not add an open-source claim until a license decision has been made.
- Retain this positioning in future README and About edits. Preserve the clear download choices and avoid lists of unrelated keywords.
