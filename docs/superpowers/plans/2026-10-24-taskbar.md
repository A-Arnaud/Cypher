# Cypher Taskbar Implementation Plan

> For agentic workers: REQUIRED SUB-SKILL: Use superpowers:executing-plans or superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox syntax for tracking.

Goal: Compact, genuinely embedded Windows 10 quotas with first-run details, dock button, persistent startup mode and click-to-open.

Architecture: Electron owns settings, quota collection and the main window. A separate C# WinForms/Win32 helper owns only the child taskbar surface and reversible space reservation; JSON lines over stdio carry sanitized display data and lifecycle events. A per-user installed build supplies a stable startup executable; portable stays available without registering a temporary executable.

Tech Stack: Existing TypeScript, React, Electron, Vitest, Playwright; Windows .NET Framework C# compiler already located on this host.

Spec: docs/superpowers/specs/2026-10-24-taskbar-design.md

## Global Constraints

- Windows 10 x64, primary horizontal taskbar; reject unsupported configurations explicitly.
- Maximum display width 220 logical pixels at 100% DPI; at most three pinned profiles plus +N.
- First new installation opens details; preserve existing users' summary preferences.
- Keep weather, notification area, consent isolation and existing state location intact.
- No overlay fallback, DLL injection, automatic PC reboot, new npm native dependency or credential exposure.
- No commit/push without user request. All acceptance claims need actual execution evidence.
- Follow Windows taskbar auto-hide/fullscreen behavior; never force visibility over fullscreen. Secondary/vertical bars unsupported, transition falls back to visible details.
- Explicit undock action leaves startup unchanged; only first activation enables startup, subsequent activations respect user/Windows disablement. Persist a taskbarOnboarded:boolean marker to distinguish first activation; migrate missing marker to false.

## Review Focus

- Explorer layout changes or crashes: discard stale HWNDs and never restore old geometry over a new shell.
- Startup helper failure: main window must remain reachable; no invisible successful-looking dock state.
- High DPI/auto-hide/full taskbar: reserve only valid available space and restore without obscuring shell controls.
- Portable extraction/update/uninstall: no startup path in a transient extraction folder, no unrelated startup registry changes.
- Multiple accounts/stale/unknown metrics: no ambiguous invented percentage or wrong profile identity.
