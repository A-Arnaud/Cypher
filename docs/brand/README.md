# Cypher repository artwork

Original SVG/PNG assets generated by `node scripts/generate-brand-assets.cjs`. The centered header, wide product image and three-card navigation take layout inspiration from [Cua's README](https://github.com/trycua/cua). No Cua logo, product art or product claims are reused.

The graphite firefly logo is the user-supplied artwork stored in `assets/logo-source.png`. Its appearance is preserved; `node scripts/make-icon.cjs` generates the application PNG, SVG wrapper and multi-resolution Windows ICO from that source. The wordmark PNG is used in the README so its raster logo displays consistently on GitHub.

The compact and detailed product views come from the account-free, English fixtures in `node scripts/capture-showcase.cjs`. Values are synthetic. The taskbar card is an illustration with synthetic values, not a native screenshot.

To regenerate documentation images on Windows with Microsoft Edge installed:

```powershell
node scripts/make-icon.cjs
node scripts/capture-public-screenshots.cjs
node scripts/capture-showcase.cjs
node scripts/generate-brand-assets.cjs
```

Inspect the resulting images for layout, language and private data before committing them. Never substitute a real-account screenshot.
